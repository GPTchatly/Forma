# Example projects

Import these through Saved projects > Import JSON. All three were assembled with
**Offline demo rules**, not live JEV, and contain prepared draft copy and decorative
placeholder art. They demonstrate editable specifications, not a model benchmark.

- `studio-north.project.json`: warm editorial studio site.
- `orbit.project.json`: dark software-product landing page.
- `stillwater.project.json`: calm coastal-stay website.

Replace example brand names, wording, images, prices and contact details before
publishing. You can refine an imported project with live JEV after connecting a key.
