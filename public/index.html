A quick guide to Forma

    
Practical answers about building, editing and exporting your website.

    

      
About Forma

        
What can I build with Forma?
Build responsive websites and application frontends: sign-in, chat, dashboards, tables, task boards, settings, inboxes, calendars, storefronts, checkout and document editors. Edit their fields and panels, try local interactions, and export HTML.

        
What does JEV actually do?
JEV chooses supported layouts, application controls, image sizes, section and item positions, and internal element arrangements. It does not generate prose, images or source code. Use exact quoted wording or edit prepared content yourself.

      

      
Getting started

        
Can I try the app without an API key?
Yes. Choose Offline demo to try the editor, local saving and export without a key. Demo mode uses simple English keyword rules, not a live model, and makes no JEV API calls.

        
Do live requests cost money?
Live design and connection tests use your TypeSafe or OpenRouter API key and may be billed under your provider account. Enter a key in Connect JEV. A connection test makes one small request; a live design normally makes two.

        
How do I run Forma on my computer?
Install Node.js 22 or newer, extract the app folder, and run start.cmd on Windows. You can also run node server/index.mjs from that folder. The editor opens at http://127.0.0.1:4318. Keep the server running while you work.

        
Where are my projects and API key stored?
Projects are saved as files on this computer; there is no built-in cloud sync. A key entered in the connection dialog stays in the local server’s memory until the app stops. It is not saved in project files or website exports.

        
What is sent to JEV?
Only an explicit live design or connection test contacts the provider. Live design sends your prompt and relevant text and design context. Uploaded image bytes and the configured contact-email field are excluded. Anything you include in the prompt is sent, so choose its contents carefully.

      

      
Editing and saving

        
How do I change text, images and layouts?
Use Content to edit text, images, application fields and panels, and Design to adjust the theme. Inspect selects content; grips and Move menus rearrange it. Interact tries local controls and links. Locks protect existing choices during Refine and Redesign.

        
Can one project have several pages?
Yes. A project supports up to eight pages, including Home. Add a page from the page toolbar or the preview’s + menu. Pages have independent content and design while sharing the brand. Blog and article starters are editable static pages.

        
How do I save or recover my work?
Changes autosave locally. New design saves the current project, starts from blank, and saves its result as a separate project. Refine and Redesign keep the current project. Use Undo, Redo and saved checkpoints to recover editing steps.

      

      
Export and language

        
What do I get when I export a website?
Download website creates a ZIP with a self-contained HTML file for each page, editable project JSON, reference CSS and JavaScript, and license notices. Open the HTML locally or upload the HTML pages to a static host yourself. Review draft copy and image alternative text before publishing.

        
Does the contact form deliver messages?
The contact form prepares a draft in the visitor’s email app using your configured public email address. It does not send or store messages. Authentication, payments, bookings and form delivery require separate services or a backend.

        
Does changing the app language translate my website?
No. The language selector translates the editor and this help panel. Your website text, page titles and prompts stay as authored. The HTML language code in Brand settings only changes website language metadata; it does not translate copy.

        
What cookies or localStorage data does Forma use?
Forma uses no tracking or advertising cookies. Browser storage keeps your language, theme, last opened project, this notice choice, and project backups. API keys entered in the app stay in memory, not in persistent browser storage or project files. When you test a connection or run a live build, your key passes through Forma's backend to your selected provider, OpenRouter or TypeSafe.

        
How can I contact support?
For questions or feedback, use the project's source repository.
